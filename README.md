# OniCanvas Companion

OniCanvas is a wireless, tactile companion application designed for digital artists using Clip Studio Paint (CSP) on Windows. It transforms an Android tablet or phone into an interactive hardware-like macro control pad, complete with glassmorphic layouts, HSL palette selection, gesture touchpad, and live telemetry tracking.

## Root Project Structure
- `app/`: Android mobile application source code and assets.
- `gradle/`: Gradle wrappers and dependency version catalogs.
- `docs/`: Protocol specifications, setup instructions, and architecture documents.
- `build.gradle.kts` & `settings.gradle.kts`: Gradle build configuration files.
- `gradle.properties`: Project-wide settings and compiler optimizations.
