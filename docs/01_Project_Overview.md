# 01 - Project Overview

# Project Name

**OniCanvas**

## Vision

OniCanvas is a professional Android companion application that
transforms a phone or tablet into a customizable wireless control
surface for digital artists using Clip Studio Paint and, in future
releases, other creative software.

## Problem Statement

Digital artists frequently interrupt their workflow to use keyboard
shortcuts, navigate complex menus, or switch between input devices.
Existing macro pads are often generic and not optimized for drawing
workflows.

OniCanvas aims to reduce these interruptions by providing touch-first
controls designed specifically for artists.

## Goals

-   Reduce keyboard dependence while drawing.
-   Speed up repetitive actions.
-   Provide a customizable workspace.
-   Support both phones and tablets.
-   Deliver low-latency communication with a Windows companion
    application.
